# 📘 C# Learning & Mastery Resources

A curated list of high-quality resources to **learn, reinforce, and master C#**, from fundamentals to professional-level understanding.

---

## 🌟 Core Foundations (Non-Negotiable)

### **Tim Corey – IAmTimCorey**

> *Deep fundamentals, professional mindset, zero fluff*

* **Platform**: YouTube, Paid Courses
* **Link**: [https://www.youtube.com/@IAmTimCorey](https://www.youtube.com/@IAmTimCorey)
* **Website**: [https://www.iamtimcorey.com](https://www.iamtimcorey.com)

**Why**

* Explains *why* things work, not just *how*
* Strong emphasis on clean code and architecture
* Excellent coverage of OOP, interfaces, dependency injection

**Recommended Topics**

* C# Fundamentals
* Object-Oriented Programming (OOP)
* Interfaces & SOLID principles
* ASP.NET basics

---

### **Microsoft Learn (Official Documentation)**

> *Authoritative, up-to-date, structured*

* **Platform**: Microsoft Learn
* **Link**: [https://learn.microsoft.com](https://learn.microsoft.com)

**Why**

* Official C# and .NET learning paths
* Modern language features explained clearly
* Best source for current best practices

**Recommended Areas**

* C# language basics
* .NET runtime and libraries
* LINQ
* Async / Await

---

## 🧠 Practice & Reinforcement

### **Exercism – C# Track**

> *Learn by doing, with mentor feedback*

* **Platform**: Exercism
* **Link**: [https://exercism.org/tracks/csharp](https://exercism.org/tracks/csharp)

**Why**

* Small, focused exercises
* Encourages idiomatic C#
* Feedback helps correct bad habits early

---

### **LeetCode (Selective Use)**

> *Problem solving, not language learning*

* **Platform**: LeetCode
* **Link**: [https://leetcode.com](https://leetcode.com)

**Use For**

* Algorithmic thinking
* Logic and performance tuning

⚠️ **Note**: Not recommended for beginners learning C# syntax.

---

## 📖 Books (Structured, Deep Learning)

### **C# Player’s Guide – RB Whitaker**

> *Beginner-friendly, concept-first approach*

* Excellent explanations
* Gradual progression
* Strong mental models

---

### **CLR via C# – Jeffrey Richter**

> *Advanced, runtime-level understanding*

* Memory management
* Threads and concurrency

📌 Recommended after mastering fundamentals.

## 🇸🇬 Practical Learning (Highly Recommended)

### **Your Own Projects & Codebases**

> *Best teacher is real code*

* Build console apps first
* Refactor existing C# projects
* Read enterprise-style code (common in SG: finance, gov, logistics)

---

## 🔁 Suggested Learning Flow

1. Learn fundamentals – Tim Corey / Microsoft Learn
2. Reinforce concepts – Exercism
3. Build small projects – Console → Web
4. Revisit fundamentals – Concepts will click deeper
5. Read real code – GitHub / work projects

---

**Must-Have**

* Tim Corey

**Nice-to-Have**
